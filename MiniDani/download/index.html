Set up MiniDani

  1. Extract the release ZIP.
  2. Run sh install.sh on Linux or macOS, or py -3 install.py in Windows PowerShell.
  3. Drag the installed MiniDani.rbxmx into a blank Studio place. Right-click the MiniDani folder in Explorer and choose Save as Local Plugin.
  4. Open MiniDani from the Plugins toolbar, connect the companion, and sign in with Roblox.
